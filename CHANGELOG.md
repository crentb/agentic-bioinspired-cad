## [0.1.0] - 2026-09-30

Initial public release.

### Added
- **Generator families** for single-material, damage-tolerant architectures:
  helicoidal / Bouligand laminates with seven rotation laws and modeled weak-plane interfaces
  (`abcad.generators.helicoidal`); woven lattices in an exact Tier-1 form driven by the vendored
  woven-lattice engine and a compact, model-emittable Tier-2 form, with a Blender-free watertight
  path (`abcad.generators.woven`); and enamel-decussation rod lattices with three twist laws
  (`abcad.generators.enamel`).
- **Agentic design loop** (`abcad.agent`, `python -m abcad.agent`): a subprocess-isolated code
  emitter, headless Blender build and render with a structured mesh-statistics protocol,
  retrieval over the shipped exemplar corpora, a schema-constrained vision critic, code-fixer and
  code-designer repair agents with stall guards, an approval latch, a single-pass manufacturability
  gate with uniform auto-scaling, and a run manifest written on every terminal path. Runs fully
  locally within 16 GB of unified memory: before Phase 1 it unloads any chat model the local
  daemon still holds, and a terminated or interrupted parent takes the Phase-1 child down with it.
  Validated live on the target machine (TM-4): five runs from a failing emit, including an
  offline run and a 58 mm target-size run, each ended with a certified print file, and a full
  run from the text prompt alone certified a woven lattice.
- **Printing tools** (`abcad.printing`): the TM-2 printability audit (wall-thickness ladder,
  clearance, enclosed voids, overhang; FDM and resin verdicts), certified FDM variants, and a
  watertight remesher for open-tube lattices.
- **FEA** (`abcad.fea`): plated voxel-hex meshing, linear effective modulus in tension, a
  finite-strain neo-Hookean total-Lagrangian tension solver that records Newton convergence for
  every load step and exits non-zero when a step fails to converge, an algebraic-multigrid solver
  path, and the TM-3 flaw-seeded damage-tolerance retention metric.
- **Fracture** (`abcad.fracture`): MOOSE phase-field fracture and J-integral decks with
  generators, analysis and rendering scripts (TM-6), including the validation gate, the
  closed-form K benchmark, orientation and pitch sweeps, 3D crack twisting, and non-fused woven
  cells with frictional contact.
- **Evidence records** (`results/`): the text records behind every documented number, re-verified
  by the gold tests, including the live end-to-end validation of the design loop
  (`results/agent_runs/validation_2026-09-26/`).
- **Documentation**: literature basis, generator specifications, build-to-print runbook,
  printability, FEA, fracture, agent-loop and performance documents; a one-page pipeline
  schematic; controlled documents ABCAD-SOP-001 (loop operation) and ABCAD-QMS-002 (definitions
  and test methods); and a figure set regenerated by `docs/figures/src/make_figures.py` from the
  evidence records and the simulation outputs, in one visual style for renders and charts.
- **CI/CD and DevSecOps**: lint, format, type and test gates on Python 3.10 to 3.14; packaging
  validation; gitleaks, bandit and pip-audit security gates; a trivy-scanned container with a
  cosign-signed SBOM; CodeQL for the Python code and the workflows; dependency review; OpenSSF
  Scorecard; weekly re-scans; Dependabot; and a release pipeline with PyPI Trusted Publishing,
  signed GHCR images with SLSA build provenance, and GitHub Releases.
